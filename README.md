# FORM / FIELD Architecture

Professional multi-page Next.js 16 architecture portfolio designed as a client-facing showcase by Nolixia Technology.

## Pages

- Home
- Projects index
- Six project detail pages
- Studio
- Approach
- Journal
- Contact
- Sitemap and robots

## Run

```bash
npm install
npm run dev
```

## Before publishing

Replace `https://formfield.example` with the real domain in `app/layout.tsx`, `app/sitemap.ts` and `app/robots.ts`. Replace the demo contact details and connect the contact form to your preferred email or database service.
